# ✊ Pedra, Papel e Tesoura

Jogo clássico de Pedra, Papel e Tesoura desenvolvido em Python, rodando diretamente no terminal. O jogador compete contra o computador, com placar de vitórias, derrotas e empates.

![Python](https://img.shields.io/badge/Python-3.8%2B-3776AB?logo=python&logoColor=white) ![Projeto de estudo](https://img.shields.io/badge/Projeto-de%20estudo-blue)

---

## ✨ O que ele faz

- Permite escolher entre pedra, papel e tesoura
- Utiliza o módulo `random` para selecionar a opção do computador
- Compara as escolhas para determinar o resultado da rodada
- Identifica vitórias, derrotas e empates
- Mantém um placar atualizado durante a execução
- Permite continuar jogando ou encerrar o programa

## 🚀 Como rodar

Precisa apenas do Python 3 instalado. Não é necessário instalar bibliotecas externas.

```bash
python nome_do_arquivo.py
```

## 📋 Menu

| **Opção** | **Ação** |
|---|---|
| **1** | Pedra |
| **2** | Papel |
| **3** | Tesoura |
| **sair** | Encerrar o jogo |

## 🖥️ Exemplo de uso

```text
Jogo de pedra, papel e tesoura

Computador escolheu: Tesoura

Escolha uma das opções:
1 - Pedra
2 - Papel
3 - Tesoura

Escolha uma das opções: 1

Sua escolha foi: pedra
Você ganhou!

Placar: Você: 1 | Computador: 0 | Empates: 0
```
